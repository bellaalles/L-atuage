# AGENTS.md

## Что это
Статический концепт-редизайн latuage.com (L'ATUAGE cosmetic, Минск).

## Как собирается
`python3 _build/gen.py` — генерирует `index.html`, `catalog.html`,
`product.html`, `about.html`, `journal.html`, `article.html`, `contacts.html`
из шаблонов в `_build/`.
HTML руками не править: правки затрутся при следующей сборке.

- `_build/gen.py` — head, шапка, футер, общая обвязка страниц.
- `_build/index_body.py` — тело главной по секциям.

## Данные
`assets/js/data.js` — единственный источник товаров (60 позиций, id вида
`pomada-inred`). Карточка товара читает `?id=`, каталог — `?cat=`.

## Журнал
`journal.html` — список статей (рендерится из `window.ARTICLES`), фильтр по рубрикам.
`article.html?id=…` — статья: лид, обложка, буквица, подзаголовки, цитаты,
блок «Из статьи» с товарами и переход к следующей статье.

## Проверка
```bash
python3 -m http.server 8000
```
`assets/img/products/` — 60 вырезанных продуктов на прозрачном фоне,
единственный источник изображений (стоковых фото в проекте нет).

## Правила
- Никаких внешних зависимостей и сборщиков: только HTML/CSS/JS.
- Токены дизайна — в `:root` в начале `assets/css/style.css`.
- Фото чужих брендов и процедурные стоки не использовать.

## Визуальный язык
- База — плотный гротеск Inter Tight (текст, подписи), акцент — Bodoni Moda
  (заголовки, цитаты, цифры). Палитра: бумага `#f8f4ed`, кость, песок,
  золото `#a98a4f`, красный `#9e1220`.
- Bodoni Moda не содержит глифов `—`, `–`, `+`: в антикве вместо них
  `<span class="dash"></span>` и `<span class="plus">+</span>`.
  В JS-контенте (`app.js`) тире в заголовках подставляет `dashify()`.
  Запятая и двоеточие в этой гарнитуре выглядят как точки — это особенность
  шрифта, не баг.
- Продукт всегда стоит на цветной плите (`--tint` по категории), изображения
  позиционируются абсолютно (`inset` + `object-fit: contain`) — проценты
  высоты внутри `aspect-ratio`-контейнера не работают.
- Красный `--red` — единственный акцент; всё остальное чёрное/белое/цветные плиты.
- Нумерация секций главной (`01 / …`–`11 / …`) задаётся в `_build/index_body.py`
  вручную — при вставке новой секции перенумеровывать хвост.
- Кадры в карточках журнала держим через `aspect-ratio` на контейнере
  (`.post__media`), а не на `img`: у фото разная пропорция и низ карточек разъезжается.
- Карточные фото товаров проходят через `_build/enhance_products.py`:
  обрезка по альфе, единая портретная рамка 4:5 с полями 8%, unsharp mask,
  webp q92. Скрипт идемпотентен — можно гонять повторно после добавления фото.
  Плитки под них: `.pcard__media`, `.plate`, `.pdp__main` — `aspect-ratio: 4 / 5`,
  картинка на 100% рамки, тень через `drop-shadow`.
