# L'ATUAGE — концепт современного сайта

Редизайн сайта белорусского производителя декоративной косметики
[latuage.com](https://latuage.com/): статический сайт без сборки, который
открывается в любом браузере и разворачивается где угодно.

## Что внутри

- `index.html` — главная: герой-блок, категории, хиты, производство,
  принципы, лукбук, путь продукта, журнал, отзывы, соцсеть, география, подписка.
- `catalog.html` — каталог с фильтрами по категориям, поиском и быстрым просмотром.
- `product.html?id=…` — карточка товара с галереей, оттенками и составом.
- `about.html` — история бренда, производство, цифры.
- `contacts.html` — где купить, оптовым клиентам, FAQ, форма связи.

## Стек

Чистые HTML/CSS/JS. Никаких зависимостей и сборки:

- `assets/css/style.css` — дизайн-система (типографика, сетка, компоненты, анимации).
- `assets/js/data.js` — каталог товаров (60 позиций, 4 категории).
- `assets/js/app.js` — рендер каталога, фильтры, поиск, модалка быстрого просмотра,
  слайдеры, скролл-анимации, мобильное меню.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

## Как это переносится в продакшн

Вёрстка разбита на компоненты в `_build/` — генератор страниц на Python.
Каждая секция собирается в готовый HTML, поэтому тот же код ложится
на CMS (InSales, WordPress, Shopify) или на фреймворк без переписывания дизайна.

> Демонстрационный проект: фото и товары взяты из открытых источников
> и используются только для показа концепции.
