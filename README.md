# L'ATUAGE — концепт современного сайта

Редизайн сайта белорусского производителя декоративной косметики
[latuage.com](https://latuage.com/): статический сайт без сборки, который
открывается в любом браузере и разворачивается где угодно.

**Живая версия:** https://bellaalles.github.io/L-atuage/

## Что внутри

- `index.html` — главная: герой-блок, витрина категорий, хиты, цифры,
  подбор оттенка, производство, палитра, журнал, отзывы, география, подписка.
- `catalog.html` — каталог с фильтрами по категориям, поиском и быстрым просмотром.
- `product.html?id=…` — карточка товара с галереей, оттенками и составом.
- `journal.html` — журнал: рубрики, шесть статей, обложки и лиды.
- `article.html?id=…` — статья с буквицей, подзаголовками, цитатой и блоком товаров.
- `about.html` — история бренда, производство, цифры.
- `contacts.html` — где купить, оптовым клиентам, FAQ, форма связи.

## Визуальный язык

Вторая версия сознательно построена на трёх вещах: плотная гротескная
типографика, цветовые поля и продуктовые вырезы самого бренда.

- Никакого стокового фото и моделей: только упаковка L'ATUAGE на цветных
  плитах — каждый оттенок получает свой фон.
- Цветовые токены категорий: глаза — песок, губы — пудрово-розовый,
  лицо — масло, руки — шалфей, аксессуары — лаванда.
- Плотный гротеск Inter Tight в основе и Bodoni Moda в акцентах: крупные
  антиквенные заголовки с курсивным красным, буквицы в статьях.
- Тёплая палитра бумаги и кости, золото `#a98a4f`, единственный громкий
  цвет — красный `#9e1220`.
- Интерактив: интерактивный подбор оттенка с перекраской сцены, быстрый просмотр,
  избранное, drag-скролл витрин, скролл-анимации, мобильное меню.

## Стек

Чистые HTML/CSS/JS. Никаких зависимостей и сборки:

- `assets/css/style.css` — дизайн-система (типографика, сетка, компоненты, анимации).
- `assets/js/data.js` — каталог товаров (60 позиций, 4 категории) и статьи журнала.
- `assets/js/app.js` — рендер каталога, фильтры, поиск, модалка быстрого просмотра,
  слайдеры, скролл-анимации, мобильное меню.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

## Как это переносится в продакшн

Вёрстка разбита на компоненты в `_build/` — генератор страниц на Python.
Каждая секция собирается в готовый HTML, поэтому тот же код ложится
на CMS (InSales, WordPress, Shopify) или на фреймворк без переписывания дизайна.

> Демонстрационный проект: изображения продуктов взяты с официального сайта
> latuage.com и используются только для показа концепции. Стоковых фотографий
> и чужих брендов на сайте нет.
